🚀 Por que isso importa?

Fazer o download de um arquivo de 50MB no smartphone para extrair uma única média municipal consumiria dados móveis valiosos do usuário e causaria timeouts frequentes. Centralizando o processamento no backend, o app economiza 99.8% de dados e responde de forma praticamente instantânea.

🛡️ Fallback e Resiliência

Se por alguma eventualidade o banco de dados estiver indisponível ou a cidade não possuir registros no cache, a função `route-estimate` tenta calcular a média estadual daquela UF. Se ainda assim falhar, realiza o download direto em Deno como plano de contingência.

// Consulta resiliente ao cache com fallback dinâmico
async function getRegionalFuelSuggestion(supabaseClient: any, state: string, city: string, fuelType: string) {
  // 1. Tentar buscar pelo par exato cidade + estado
  const { data: cityData } = await supabaseClient
    .from('fuel_prices')
    .select('average_price')
    .eq('state', state.toUpperCase())
    .eq('city', city.toUpperCase())
    .eq('product', fuelType.toUpperCase())
    .maybeSingle()

  if (cityData?.average_price) {
    return cityData.average_price; // Retorno rápido: ~5ms no Supabase
  }

  // 2. Se não houver, obter média de todo o estado cadastrado no cache
  const { data: stateData } = await supabaseClient
    .from('fuel_prices')
    .select('average_price')
    .eq('state', state.toUpperCase())
    .eq('product', fuelType.toUpperCase());

  if (stateData && stateData.length > 0) {
    const sum = stateData.reduce((acc: number, row: any) => acc + row.average_price, 0);
    return sum / stateData.length;
  }

  // 3. Fallback: Parsear o CSV do site oficial diretamente se nada mais funcionar
  return await fetchAndParseANPFallback(state, city, fuelType);
}

-- Tabela para guardar os dados médios calculados
create table public.fuel_prices (
  state text not null,
  city text not null,
  product text not null,
  average_price numeric(10, 4) not null,
  updated_at timestamp with time zone default timezone('utc'::text, now()) not null,
  constraint fuel_prices_pkey primary key (state, city, product)
);

Como Configurar Localmente

Prepare o ambiente para rodar o app no seu emulador ou dispositivo físico em poucos minutos.

1

Clonar Repositório

Clone e acesse a subpasta do projeto:

git clone https://github.com/ViniciusCostaGrillo/autofy.git
cd autofy/autofy
2

Configurar Variáveis

Copie o modelo `.env.example` e coloque suas chaves do Supabase:

cp .env.example .env
3

Instalar e Iniciar

Baixe as dependências e inicie o servidor Expo CLI:

npm install
npm run start
